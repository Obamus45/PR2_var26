# Вариант 26 — этапы 1–3

CLI-приложение на Python читает YAML-конфигурацию и строит транзитивный граф зависимостей Ubuntu APT. Для сетевого получения метаданных используется собственный разбор Packages-индексов на стандартной библиотеке Python, без запуска `apt` и сторонних библиотек получения зависимостей.

## Параметры YAML

| Ключ | Назначение |
|---|---|
| `package_name` | Имя корневого пакета |
| `repository` | URL APT suite/index или путь к тестовому графу |
| `test_mode` | Если `true`, читать локальный тестовый граф; если `false`, обращаться к Ubuntu APT-репозиторию |
| `output_file` | Имя SVG-файла (потребуется на этапе визуализации) |
| `ascii_tree` | Флаг ASCII-дерева (потребуется на этапе визуализации) |
| `filter_substring` | Не обходить пакеты, содержащие эту подстроку; пустое значение отключает фильтр |

## Запуск

Нужен Python 3.10+ и PyYAML для YAML-конфигурации.

```bash
python -m pip install -r requirements.txt
python app.py
```

Путь к альтернативной конфигурации задаётся через `--config`:

```bash
python app.py --config config-chain.yaml
```

Успешный запуск печатает конфигурацию, прямые зависимости корневого пакета и список смежности полного графа в порядке BFS.

## Этап 3: алгоритм и фильтрация

`dependency_graph.py` выполняет обход в ширину. Очередь обрабатывается рекурсивной функцией `visit_next`; множество `visited` не допускает повторного добавления узлов и зацикливания. Ребро на уже посещённый пакет остаётся в графе, так что циклы корректно отображаются. При заданном `filter_substring` совпадающие узлы исключаются из графа и не обходятся. Если фильтр исключает сам корневой пакет, выводится ошибка.

В сетевом режиме каждый пакет раскрывается через его `Pre-Depends` и `Depends`. APT-индексы разбираются стандартной библиотекой; разобранные индексы кэшируются, чтобы не загружать один и тот же файл для каждого узла. В альтернативе вида `foo | foo-compat` обе возможности представлены отдельными рёбрами графа. Это объединение потенциальных альтернатив, не разрешение конкретного варианта apt.

## Тестовый режим

В тестовом режиме поле `repository` указывает на файл простого ориентированного графа. Формат строки: `ПАКЕТ: ЗАВИСИМОСТЬ1, ЗАВИСИМОСТЬ2`. Имена пакетов и зависимостей — только большие латинские буквы. Пакет без зависимостей задаётся, например, как `E:`. Узлы, указанные справа, но не описанные отдельной строкой, считаются листьями. Строки, начинающиеся с `#`, являются комментариями.

В `test-repository.txt` собраны случаи для демонстрации:

1. **Ромб и цикл:** `A -> B,C`, `B -> D`, `C -> D,E`, `D -> A`.
   ```bash
   python app.py --config config.yaml
   ```
   Ожидаемый BFS: `A -> B -> C -> D -> E`; обратное ребро `D -> A` напечатано, но `A` повторно не обходится.
2. **Цепочка:** `F -> G -> (лист)`.
   ```bash
   python app.py --config config-chain.yaml
   ```
3. **Самозависимость:** `H -> H`.
   ```bash
   python app.py --config config-self-cycle.yaml
   ```
4. **Фильтр:** `config-filter.yaml` исключает `C` и не обходит его ветвь к `E`.
   ```bash
   python app.py --config config-filter.yaml
   ```

## Реальный Ubuntu APT-репозиторий

В `config-ubuntu.example.yaml` приведён пример для пакета `bash` и Ubuntu Noble:

```bash
python app.py --config config-ubuntu.example.yaml
```

URL должен указывать на конкретный suite, например `https://archive.ubuntu.com/ubuntu/dists/noble/`, или на файл `Packages` / `Packages.gz` / `Packages.xz` / `Packages.bz2`. Для suite приложение читает `Release`, выбирает компоненты и архитектуру `amd64` (если она доступна) и последовательно ищет пакет в индексе каждого компонента. URL корня зеркала без `/dists/<suite>/` недостаточен: в конфигурации нет отдельного параметра для выпуска Ubuntu.

Пакеты, которые отсутствуют в доступных индексах (например, виртуальные зависимости без выбранного provider), остаются конечными узлами; программа сообщает о них после графа.

## Проверки

```bash
python -m unittest -v
```

Автотесты проверяют конфигурацию, разбор APT Packages (включая сжатый индекс и альтернативы), формат тестового графа, BFS-порядок, фильтрацию, цепочку и циклы.
